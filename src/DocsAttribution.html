Overview

The B-Bucks Economy Scripts is a financial management ecosystem engineered for virtual economies in educational environments.

Project Scope

Handles account overrides, investment ledgers, transaction routing, and cached sheet lookups.

Core Workflow

System actions originate from custom sidebar dialogs, driving gas functions via server calls.

Balance Management

Manual Adjustments

Add or remove currency directly with optional audit notes across target ranges.

Tax Calculations

Run automatic percentage reductions across target ranges while preserving exact floating point values.

Investment Banking

Yield Rates

Configures yield rates, recurring interest payouts, and user portfolios.

Caching & Performance

CacheService Strategy

Utilize CacheService to store processed matrix maps and eliminate redundant Sheet API read cycles.

const cache = CacheService.getScriptCache();
const cachedData = cache.get("BALANCE_CACHE");

Direct Range Block Selection

Range operations target direct matrix arrays rather than hardcoded column indices across active sheets.
