Project Overview

The B-Bucks Economy Scripts is a comprehensive financial management system designed for educational environments. It provides tools for managing virtual currency, tracking investments, and maintaining detailed transaction records.

Features

  • Manual Balance Management - Adjust B-Bucks balances with override capabilities
  • Income & Expense Tracking - Record and categorize financial transactions
  • Investment Banking - Manage investment portfolios and track returns
  • Transaction Records - Comprehensive audit trail of all activities
  • Banking Settings - Configure system parameters and restrictions
  • Multi-tier Caching - Optimized data retrieval with fallback strategies

Technical Stack

Language: TypeScript / Google Apps Script

Frontend: HTML5, CSS3

Backend: Google Sheets API, Apps Script Runtime

Data Storage: Google Sheets, Script Properties, Cache Service
